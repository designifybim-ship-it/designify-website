DESIGNIFY MULTI-PAGE WEBSITE

Open index.html to start.

Pages are separate HTML files: Home, About, Services, Pricing, Portfolio, Reviews and Contact. Each portfolio business also has its own page inside /projects.

IMPORTANT: Keep the entire folder together. The HTML pages use the /assets folder for logos, CSS, JavaScript and portfolio images.


SOCIAL + AD LINKS
Open assets/site.js and edit the DESIGNIFY_LINKS block at the very top. Paste the full Instagram, Facebook and Behance URLs there. WhatsApp is already set to +1 (246) 230-1679.

The homepage contains two editable ad/promotion spaces directly below the scrolling specialties strip. You can replace their copy in index.html and set their click destinations with primaryAd and secondaryAd in assets/site.js.


Pricing update: standard service starting prices were increased and a Custom Packages section was added. Custom package inquiries are available from Pricing, Services, and Contact.
